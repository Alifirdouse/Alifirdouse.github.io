About

How I work

I work as an L2 Support Engineer at CareStack, where I investigate production issues, write SQL data fixes, and watch system health through Prometheus, Loki and Grafana across Azure and Kafka-based services.

I'm also a full-stack developer working with the MERN stack (MongoDB, Express, React, Node.js) and building Gen AI features on top of large language models.

On the data side, I've built a Lakehouse pipeline in Microsoft Fabric that merges SQL, Excel, JSON, CSV and XML sources into a Power BI dashboard, trained regression models to forecast crime hotspots, and written SQL to profile thousands of FIFA players.

I care about the boring parts done well: clean joins, honest charts, and models evaluated with the right metric. My work lives on GitHub as notebooks, SQL scripts and write-ups.
